# Pre-Built Gaussian Parameter Collector Kernels

This folder contains a list of collector configurations used to generate Slang kernels at build time, generate the associated CUDA code and slangtorch integration Torch extension, compile those and produce a Torch extension that can be loaded faster at runtime to access those kernels.

The files in this folder are generated by running training (or other runs) and setting the environment variable `OUTPUT_CONFIGURATIONS_PATH` to a path where to output the .json file. They must then be copied to this folder and renamed according to the config it represents.

It will then be automatically picked up by the build system when generating the pre-built collector kernel libraries.
