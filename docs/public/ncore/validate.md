# Validate Data Quality for NVIDIA Neural Reconstruction

To generate the highest quality simulations using NVIDIA Neural Reconstruction, you must first ensure that the quality of your input data is high.

Follow the best practices in [Ensure Data Quality](data-quality) to get the best output using NuRec. Then, use the Data Quality Toolkit to validate
your data quality before using NuRec to generate scenes.

## Run the Data Quality Toolkit

Use the interactive NCore Data Sanity Check (data_sanity_check.ipynb) Jupyter Notebook to validate your data quality.

Download the NCore package from NGC, and unzip `ncore-docs.zip`. Nagivate to `/public/tutorial/data_sanity_check.ipynb` and load the notebook.
