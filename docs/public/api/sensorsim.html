Services

service SensorsimService

SensorsimService defines the RPC interface for interacting with the sensor simulator. It provides methods for rendering RGB images and lidar data, querying available scenes, cameras, trajectories, and ego masks, as well as shutting down the simulator.

rpc render_rgb
Request: sensorsim.RGBRenderRequest
Response: sensorsim.RGBRenderReturn

Renders an RGB image based on the provided request parameters.

rpc render_lidar
Request: sensorsim.LidarRenderRequest
Response: sensorsim.LidarRenderReturn

Renders lidar data based on the provided request parameters.

rpc get_version
Request: common.Empty
Response: common.VersionId

Returns the version of the sensor simulator.

rpc get_available_scenes
Request: common.Empty
Response: common.AvailableScenesReturn

Returns the list of available scenes.

rpc get_available_cameras
Request: sensorsim.AvailableCamerasRequest
Response: sensorsim.AvailableCamerasReturn

Returns the list of available cameras for a given scene.

rpc shut_down
Request: common.Empty
Response: common.Empty

Shuts down the sensor simulator.

rpc get_available_trajectories
Request: sensorsim.AvailableTrajectoriesRequest
Response: sensorsim.AvailableTrajectoriesReturn

Returns the list of available trajectories for a given scene.

rpc get_available_ego_masks
Request: common.Empty
Response: sensorsim.AvailableEgoMasksReturn

Returns the list of available ego masks.
