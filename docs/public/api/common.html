message AABB

AABB represents an axis-aligned bounding box.

Field Type Description
1 size_x float

The size of the box along the x-axis.
2 size_y float

The size of the box along the y-axis.
3 size_z float

The size of the box along the z-axis.

Minor version number.
3 patch uint32

Patch version number.

DynamicState represents the dynamic state of an object, including velocities.

message Pose

Pose represents a 3D pose with translation and rotation.

Field Type Description
1 vec common.Vec3

The translation vector. Convention: translation (vec) is applied first.
2 quat common.Quat

The rotation quaternion. Convention: rotation (quat) is applied after translation.

message PoseAtTime

PoseAtTime represents a pose at a specific timestamp.

Field Type Description
1 pose common.Pose

The pose at the given timestamp.
2 timestamp_us fixed64

The timestamp in microseconds.

message Quat

Quat represents a quaternion for 3D rotations.

Field Type Description
1 w float

The w (real) component of the quaternion.
2 x float

The x (i) component of the quaternion.
3 y float

The y (j) component of the quaternion.
4 z float

The z (k) component of the quaternion.

Field Type Description

message Trajectory

message VersionId

VersionId contains versioning information for the API and implementation.

Field Type Description
1 version_id string

The version identifier string (e.g., "1.2.3").
2 git_hash string

The git hash of the build.
3 grpc_api_version common.VersionId.APIVersion

The gRPC API version (should be set to alpasim_grpc.API_VERSION_MESSAGE).

Any additional data such as hardware config can be added here in the future.
